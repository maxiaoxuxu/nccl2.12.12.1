# 源码、注释与图示怎样一起看

第一次使用建议先看 [12_使用方法与编号说明.md](12_使用方法与编号说明.md)，其中详细解释了F/T/V/B等编号、图中的C0/X0，以及打开和操作步骤。

首先打开 **[11_源码注释与图示对照_离线版.html](11_源码注释与图示对照_离线版.html)**。它将121个源码/构建文件、全部中文注释、7881个符号定位及45张图全部内嵌；单独下载这一份HTML也可断网使用，不需要安装编辑器插件、Python、Node或启动本地服务。

## 1. 在同一页看源码和图

| 操作 | 实际效果 |
| --- | --- |
| 点击顶部Ring AllReduce / Simple genericOp | 左边看源码与注释，右边看图和分析 |
| 搜索函数名或F编号 | 跳到当前注释版源码的函数说明；有绑定时同时显示图 |
| 搜索结构体名或T编号 | 定位类型与字段，并显示已有的结构协作图 |
| 搜索变量名或V编号 | 定位具体声明，按所在人工绑定代码段/函数/结构体查图；不会把未单独画过的变量冒充成独立图示 |
| 点击源码行号 | 黄色标出当前行，浅蓝色表示当前图对应的代码范围 |
| 滚动源码 | 开启“滚动源码时跟随图示”时，按当前代码范围切换图与分析 |
| 点击源码注释中的B编号 | 直接定位此绑定，例如B0007对应AR完成本块归约并开始传播 |
| 选择本文件的代码主题 / 上一处 / 下一处 | 按当前文件的代码阶段阅读 |
| 右侧按图示反查源码 | 选择任一张图，列出关联函数、结构体和代码段，点击后回到准确位置 |
| 点击放大图示 | 在大视图阅读图中文字，Esc关闭 |
| 当前定位链接 | 保留符号、绑定编号及当前行，便于收藏定位信息 |

源码保留全部中文注释，行号来自当前版本文件。图是逻辑关系示意，不是CUDA线程锁步、每一条WQE或每个QP的动画。

## 2. 在普通源码编辑器里读

普通 `.cc/.h` 文本注释本身不会渲染SVG。相关函数/结构体前增加了 **“中文精读：图示绑定 V3.3”**：列出F/T编号、B编号、图文件名和离线对照页定位。

例如在 `src/collectives/device/all_reduce.h` 中读到完成归约的阶段，可以找到：

```text
[B0007] 完成本块归约并开始结果传播
图：allreduce-step-3，11-recvReduceCopySend
定位：#symbol=F0058&binding=B0007
```

在对照页搜索 `B0007`，即可看到这段实际源码、原有注释、最终归约/首次转发图及分析。图名与 `docs/zh_CN/visuals/` 中SVG同名。绑定范围也包含紧邻执行语句前的说明注释，避免开始读下一阶段注释时仍显示上一阶段的图。

## 4. 当前实际绑定范围

人工建立125处绑定，覆盖32个源码文件中的88个关键函数、12个结构体，共100个符号。45张图均有源码入口；新补三张分别是Channel生成、IB数据QP创建、数据MR缓存。

| 主题 | 典型源码 | 绑定细节 |
| --- | --- | --- |
| Ring AllReduce | `all_reduce.h::runRing` | 容量、尾块、地址排列、首发、部分归约、最终归约、复制传播、最后接收 |
| AG / RS | `all_gather.h`、`reduce_scatter.h` | 每用户段切片、rankDest布局、起点/中间/收尾和输出偏移 |
| Broadcast / Reduce | 同名设备头文件 | root切环、root后继起步、尾节点与结果保留 |
| Simple | `prims_simple.h` | 角色、waitPeer、head/tail、direct、融合归约、屏障/发布、空slice |
| LL / LL128 | `prims_ll.h`、`prims_ll128.h` | 行flag、标记映射、warp协作和寄存器加载 |
| Channel与kernel | `init.cc`、`graph/`、`enqueue.cc`、`common.h` | 候选图、全局拼接、P2P预算、GPU视图、工作FIFO和提交 |
| Proxy与资源 | `proxy.cc`、`transport/net.cc`、`net_ib.cc` | 发布/完成/回收、QP建链、MR范围与引用、资源使用 |

绑定区分“直接对应”“调用上下文”“结构字段上下文”等关系。例如公开API包装可以关联后续Ring图，但不会说CPU包装函数自己完成GPU搬运。没有专属图的SDK/辅助函数显示“暂无绑定”，仍可查看其源码和注释。

## 5. 修改与自检

`source-diagram-bindings.json`是人工绑定表：符号ID、代码锚点、图名、关系、分析。生成器读取当前源码解析位置；绑定目标不依赖固定行号。重复片段使用显式occurrence选择；锚点缺失、图不存在或范围无法解析会报错。生成时同步刷新F/T网页索引及7881个注释条目的annotated_line；original_line仍保留原始基线位置。

```bash
python3 tools/build_source_diagram_reader.py --update-annotations
python3 tools/build_offline_docs.py
python3 tools/verify_annotations.py
python3 tools/verify_visual_models.py
python3 tools/verify_offline_docs.py
python3 tools/verify_source_diagram_bindings.py
```

仅重建页面时省略 `--update-annotations`。标准库生成器不改变原始执行语句；移除新增中文注释后仍应恢复121个原始源码/构建Git blob。

浏览器回归是 `node tools/check_source_diagram_browser.cjs`，需已安装Playwright和Chromium；阅读交付HTML不需要这些依赖。测试将单个HTML放进空目录并断网，遍历125处绑定、45张图，检查B编号、变量、滚动、反查、跨文件跳转及窄屏。它不代替CUDA/GPU实测。
